                        🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: Still showing "undefined"
Solution: 
  1. Check if Gemini service is running
  2. Submit NEW reports (old ones may not have classification)
  3. Clear browser cache (Ctrl+Shift+R)

Problem: No colors showing
Solution:
  1. Hard refresh browser (Ctrl+Shift+R)
  2. Check browser console for errors (F12)
  3. Verify admin.js was updated

Problem: Icons not showing
Solution:
  1. Check internet connection (Font Awesome loads from CDN)
  2. Verify Font Awesome link in admin.html

Problem: "Unclassified" showing
Solution:
  1. Gemini service wasn't running when report was submitted
  2. Submit a new report with Gemini service running
  3. Check API: curl http://localhost:5000/health
