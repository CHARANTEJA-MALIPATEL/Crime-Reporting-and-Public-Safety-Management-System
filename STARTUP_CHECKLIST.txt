║                  🛠️  TROUBLESHOOTING                         ║
║                                                              ║
╚══════════════════════════════════════════════════════════════╝

  Problem: Gemini service won't start
  Solution: pip install -r requirements_gemini.txt

  Problem: Port 5000 in use
  Solution: netstat -ano | findstr :5000
           taskkill /PID <process_id> /F

  Problem: Backend won't start
  Solution: cd server && npm install && npm start

  Problem: Database error
  Solution: node database/init_db.js
