═══════════════════════════════════════════════════════════════════════
                        🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "Heroku CLI not found"
Solution: Install from https://devcenter.heroku.com/articles/heroku-cli

Problem: "Git not found"
Solution: Install from https://git-scm.com/downloads

Problem: "Database connection failed"
Solution: 
  1. Get DB URL: heroku config:get JAWSDB_URL
  2. Check credentials in Heroku dashboard
  3. Restart: heroku restart

Problem: "App crashed"
Solution:
  1. Check logs: heroku logs --tail
  2. Verify environment variables
  3. Check package.json dependencies
