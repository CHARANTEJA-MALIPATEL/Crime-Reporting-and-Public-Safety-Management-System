═══════════════════════════════════════════════════════════════════════
                        🛠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "Gemini service not running"
Solution:
  1. Open new terminal
  2. cd ml
  3. python gemini_service.py
  4. Wait for "✅ Gemini API: Configured"
  5. Try reclassification again

Problem: "Connection refused"
Solution:
  Test if service is running:
  curl http://localhost:5000/health
  
  Should return: {"status": "healthy"}

Problem: "Module not found: axios"
Solution:
  cd server
  npm install axios

Problem: "Database connection error"
Solution:
  1. Check if MySQL is running
  2. Verify credentials in server/.env
  3. Test connection: node server/test_db_conn.js

Problem: Script hangs
Solution:
  1. Press Ctrl+C to stop
  2. Check Gemini service logs
  3. Restart Gemini service
  4. Try again
