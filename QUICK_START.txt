╔══════════════════════════════════════════════════════════════════╗
║ TROUBLESHOOTING                                                  ║
╚══════════════════════════════════════════════════════════════════╝

  Problem: ML service won't start
  Solution: pip install -r ml-model/requirements.txt

  Problem: "Model not loaded"
  Solution: cd ml-model && python train.py

  Problem: Port 5000 in use
  Solution: netstat -ano | findstr :5000
            taskkill /PID <process_id> /F

  Problem: Backend shows "Unclassified"
  Solution: Make sure ML service is running
            curl http://localhost:5000/health
