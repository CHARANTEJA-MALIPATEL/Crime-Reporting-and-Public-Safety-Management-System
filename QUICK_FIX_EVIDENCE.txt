║          EVIDENCE BUTTONS NOT SHOWING? - QUICK FIX             ║
╚════════════════════════════════════════════════════════════════╝

MOST LIKELY CAUSE:
You're looking at OLD reports submitted BEFORE the code changes.

QUICK FIX:
1. Make sure backend is running:
   cd server
   node server.js

2. Submit a NEW test report:
   - Login as regular user (NOT admin)
   - Go to Report Crime page
   - Fill form completely
   - UPLOAD A PHOTO (important!)
   - Submit

3. Check admin dashboard:
   - Logout and login as admin
   - Find your NEW report (top of list)
   - Should see green "Evidence Attached" box
   - Click "View Evidence" button

VERIFY DATABASE:
Double-click: CHECK_EVIDENCE_DATABASE.bat
OR run: cd server && node check_evidence.js

CHECK BROWSER CONSOLE:
1. Open admin dashboard
2. Press F12
3. Look for: "Report CR-XXXX-XXXX has evidence: filename.jpg"

IMPORTANT NOTES:
✓ Old reports won't show evidence (even if you uploaded photos)
✓ Backend must be restarted after code changes
✓ You must actually upload a file when submitting
✓ Evidence only shows for reports submitted AFTER code changes

FILES MODIFIED:
- client/js/admin.js (added debug logging)
- server/routes/reports.js (saves evidence to database)
- server/check_evidence.js (NEW - database check tool)
